一顆「發布…」。

## 範圍
### 包含
- 頂列：返回、類型、標題、檢視切換（編輯／對照／成品）、AI 按鈕（一鍵校驗＋選單）、發布…

- 配圖建議放右欄，不插進段落之間：Agent 給的 placement 是文字描述，不是段落編號。
